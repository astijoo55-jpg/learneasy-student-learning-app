# LearnEasy - Student Learning App

A simple, student-friendly educational mobile learning application built with Flutter

## Vision & Purpose
To make independent study easier by putting subject topics, short lesson notes, and quick practice in one clear place. The app is designed to feel welcoming to students who may not be confident with complicated technology.

## Core Objectives
- Make core learning actions accessible within a few taps
- Group content into subjects and individual lessons[span
- Present explanations in short, readable sections with examples
- Provide low-pressure quizzes with immediate feedback

## Navigation Flow
**Student Flow:**
Open app → Sign in / continue → Dashboard → Choose subject → Choose lesson → Read explanation/example → Take quick quiz → View feedback/score → Return to lesson library

## Planned Initial Scope
The prototype focuses on three core subjects:
- **Mathematics:** Fractions and percentages
- **Science:** Living/non-living things and states of matter
- **English Language:** Nouns and sentence building
