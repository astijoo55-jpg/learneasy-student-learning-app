# LearnEasy - Student Learning App

A simple, student-friendly educational mobile learning application built with Flutter[span_2](start_span)[span_2](end_span).

## Vision & Purpose
To make independent study easier by putting subject topics, short lesson notes, and quick practice in one clear place[span_3](start_span)[span_3](end_span). The app is designed to feel welcoming to students who may not be confident with complicated technology[span_4](start_span)[span_4](end_span).

## Core Objectives
- Make core learning actions accessible within a few taps[span_5](start_span)[span_5](end_span).
- Group content into subjects and individual lessons[span_6](start_span)[span_6](end_span).
- Present explanations in short, readable sections with examples[span_7](start_span)[span_7](end_span).
- Provide low-pressure quizzes with immediate feedback[span_8](start_span)[span_8](end_span).

## Navigation Flow
**Student Flow:**
Open app → Sign in / continue → Dashboard → Choose subject → Choose lesson → Read explanation/example → Take quick quiz → View feedback/score → Return to lesson library[span_9](start_span)[span_9](end_span).

## Planned Initial Scope
The prototype focuses on three core subjects:
- **Mathematics:** Fractions and percentages[span_10](start_span)[span_10](end_span).
- **Science:** Living/non-living things and states of matter[span_11](start_span)[span_11](end_span).
- **English Language:** Nouns and sentence building[span_12](start_span)[span_12](end_span).
